# Game design

## Fantasy

Enter a living command network. Stabilize the route with correct shortcuts. Momentum turns dusk into an electric finale. Teaching is the point; spectacle is the motivator.

## Clarity goals (highway)

1. **Readable ahead** — mid-field cues larger/more opaque; optional next-2 preview.
2. **Progressive speed** — start fair, finish thrilling; base pace still meaningful.
3. **Live scoreboard** — score/combo always glanceable; streak chain and break are unmistakable.
4. **Honest options copy** — explain approach time and density, not only BPM numbers.
5. **Tool identity** — Linear / Slack / Spotify accents without hurting legibility.

## Modes

See [PRODUCT_OVERVIEW.md](./PRODUCT_OVERVIEW.md) for product labels vs engine enums.

Design intent:

- **Learn** builds mapping; **Recall** proves it.
- **Novice → Hard** increases input complexity, not merely speed.
- **Showcase** sells the fantasy in ≤60s demos.

## Streak language

| Event | Player should feel |
|---|---|
| Hit | Contact → impact → world pulse |
| Chain building | Audio + trail escalate at 3 / 6 / 9 |
| Break | Shear, desaturate flash, combo reset — never a silent reset |

## Demo

First visit: short skippable guided run (showcase deck + optional one interlude). Esc/Skip returns to title. Revisit via How to Play. Never trap players in onboarding.

## Results

Theatrical release, not a BI dashboard:

1. Score
2. Accuracy + best combo
3. Known shortcuts / practice list
4. Leaderboard context + share

## Mini-games

Standalone speed rounds for quick dopamine; interludes as act breaks inside the highway. Both reinforce the same shortcut vocabulary. Details: [MINI_GAMES.md](./MINI_GAMES.md).

## Success metrics (product)

- Time-to-first-run &lt; 30s for new visitors
- % runs with ≥1 share or leaderboard view
- Shortcut mastery lift on practised ids (D1 aggregates)
- Demo skip rate (high skip is OK if How to Play remains available)

## Non-goals

- Punishing permadeath
- Pay-to-win tracks
- Live account farming via OAuth in MVP
